# Voiceup Demo Script

Use this script for a customer demo.

## 1. Opening

Voiceup helps organizations move from a campaign idea to a real public movement:

- Create a campaign.
- Route it to the right authority.
- Collect public signatures.
- Digitize paper sheets.
- Manage supporters and volunteers.
- Monitor operations in Command Center.

## 2. Dashboard

Show:

- Selected campaign.
- Quick Start or dashboard overview.
- Create with AI entry point.
- Navigation modules.

Talk track:

> Voiceup is not just a petition page. It is an operating system for public campaigns and movements.

## 3. SaaS Admin And Workspace

Open `/admin`.

Show:

- Organization profile.
- Geography governance.
- Workspace management.
- Branding preview.
- Team members placeholder.
- Roles/permissions placeholder.
- Billing/subscription overview.
- Integration readiness.

Talk track:

> SaaS admins can control workspace limits, geography, branding, provider readiness, and white-label setup.

## 4. Campaign Studio

Open Campaign Studio.

Show:

- Wizard steps.
- Template library.
- Campaign details.
- Slug field.
- Location governance lock.
- Authority recommendations.
- Supporter required fields.
- Media preview.
- Review quality score.
- Publish readiness.

Talk track:

> A non-technical campaign admin can create a professional campaign in minutes, while the platform keeps geography and routing controlled.

## 5. AI Campaign Copilot

Open Create with AI.

Example prompt:

```text
Repair potholes on Nandankanan Road
```

Show:

- Thinking timeline.
- Generated title, summary, description, objectives.
- Authority suggestion.
- Social posts.
- Volunteer plan.
- Press release.
- Apply accepted basics to current draft.

Talk track:

> The AI layer is provider-ready today. It shows the future workflow without requiring a live AI provider during demo.

## 6. Public Signing Page

Open `/c/{slug}`.

Show:

- Hero image.
- Title and summary.
- Why signature matters.
- Progress.
- Authority receiving petition.
- Required fields note.
- Location restriction message if configured.
- Trust section.
- Share-after-sign UI.

Talk track:

> The public page feels supporter-facing, not like an admin form. Only required fields block submission.

## 7. Field Collection

Open Field Collection.

Show:

- Paper-to-Movement Import Wizard.
- Image upload.
- PDF/CSV/Excel provider-ready UI.
- OCR review queue.
- Manual correction table.
- Duplicate detection.
- Batch approve/reject.
- Import summary.

Talk track:

> Organizations with paper signatures can digitize sheets and convert them into reviewed supporter records.

## 8. Movement CRM And Volunteer Operations

Open Movement CRM.

Show:

- Supporter profiles.
- Movement graph.
- Timeline.
- Volunteer levels.
- Volunteer Operations.
- Daily targets.
- Upload tracking.
- Leaderboard.
- District/block coordinator gaps.
- Mobile volunteer dashboard.

Talk track:

> Every supporter can become a volunteer, and every volunteer can become a coordinator.

## 9. Command Center

Open Command Center.

Show:

- Campaign operations overview.
- Geographic progress.
- Action board.
- AI Movement Brain provider-ready UI.
- Daily mission plan.
- Volunteer war room.
- Authority delivery tracker.
- Communication readiness.

Talk track:

> This is the operating room for a campaign owner: what is happening, what is weak, and what to do next.

## 10. Reports And Analytics

Open Reports.

Show:

- National Command Center 2.0.
- State/district/block progress.
- Supporter growth trend.
- Weak district/block detection.
- Online vs paper/manual split.
- Campaign comparison.
- Export PDF/CSV.
- Signer register.

Talk track:

> Leadership can see campaign performance by geography, collection channel, and readiness.

## 11. Integrations

Open SaaS Admin -> Integrations.

Show:

- AI provider settings.
- SMS, WhatsApp Business, Email, IVR.
- Payment/donation readiness.
- File storage readiness.
- Provider status.
- Test connection placeholder.
- Consent reminder.

Talk track:

> Integrations are disabled by default. Voiceup is ready for real providers without accidentally sending messages during setup.

## 12. Close

Summarize:

- Campaign creation.
- Public signing.
- Paper import.
- Volunteer operations.
- Command Center.
- Analytics.
- Provider-ready integrations.

Final line:

> Voiceup turns campaigns into structured movements with governance, field operations, and leadership visibility from day one.
