# Voiceup Volunteer Guide

This guide explains how volunteers and coordinators fit into Voiceup movement operations.

## Volunteer Operations

Volunteer Operations is part of Movement CRM.

It helps teams plan:

- Volunteer profiles.
- Coordinator hierarchy.
- Task assignment.
- Daily collection targets.
- Upload tracking.
- Field collection performance.
- Leaderboard.
- District/block coordinator gaps.
- Mobile volunteer dashboard.

Some volunteer features are provider-ready and do not persist assignments yet.

## Volunteer Levels

Voiceup supports these role concepts:

- Supporter.
- Volunteer.
- Senior Volunteer.
- Ward Coordinator.
- Panchayat Coordinator.
- Block Coordinator.
- District Coordinator.
- State Coordinator.
- National Coordinator.
- Movement Leader.

Current supporter data can be used to identify potential volunteers. Role persistence is provider-ready unless explicitly implemented.

## Daily Field Work

Typical daily mission:

1. Review today’s collection target.
2. Identify weak districts or blocks.
3. Collect signatures through public link, QR, or paper sheet.
4. Upload paper sheets in Field Collection.
5. Correct OCR/manual entries.
6. Approve valid supporters.
7. Escalate issues to coordinator.

## Paper Sheet Handling

Use Field Collection to:

- Upload scanned images.
- Review OCR results.
- Correct missing name, phone, email, and location fields.
- Flag duplicates.
- Batch approve or reject.
- Track pending uploads.

PDF/CSV/Excel imports may be provider-ready depending on current implementation.

## Coordinator Gaps

Movement CRM shows district and block coordinator gaps using available signer location data.

If a district or block appears as a gap:

- Assign a local owner.
- Set daily collection target.
- Use paper upload tracking.
- Follow up with volunteers.

## Communication

The Communication Hub is provider-ready for bulk messaging.

Do not send messages without:

- Supporter consent.
- Correct audience segment.
- Approved message template.
- Provider configuration.
- Opt-out process.

Manual WhatsApp/SMS links may open user-initiated sharing.
